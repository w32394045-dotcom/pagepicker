[English](README.md) · **简体中文**

PagePicker（打印页码选择器）把「这份文档到底要打哪几页」变成打印对话框里可以直接粘贴的页码范围——专为没有
双面器（翻页器）的打印机而做。填上文档的总页数，在顶部总览图上点几下（或者直接敲一个范围），复制结果就行。
一个 HTML 文件，使用者无需构建、无依赖、运行时不联网。

仓库：[github.com/w32394045-dotcom/pagepicker](https://github.com/w32394045-dotcom/pagepicker)

## 功能

**总页数与总览图**

- **总页数**：填文档总页数（1–2000），带步进按钮和 50 / 100 / 200 快捷值。
- **总览图**：一行或多行小方格，一格一页；已选的奇数页是蓝色，已选的偶数页是琥珀色，未选的是浅灰。悬停
  显示页码，点一下切换该页。
- **标出漏页**：打开「标出没被选中的页」，没选的页会标红，长文档里漏了哪一段一眼就能看到。
- **选择条**：实时显示「已选 X / N 页（%）」进度条，配 **全选** / **清空** / **反选** / **仅奇数** /
  **仅偶数** 快捷按钮。

**三种取页方式**

- **范围**：从 / 到数字框（带步进）加双滑块拖动。步长可选每一页或每隔一页；用 **添加** / **替换** /
  **移除** 三种方式并入当前选择。下面的框也可以直接输入 `1-5, 8, 10-13`、`odd`、`even`、`1-99/2`，详见
  [直接输入语法](#直接输入语法)。
- **奇偶**：两面都要 / 只要奇数页 / 只要偶数页 三选一；奇数页和偶数页各有独立的「从…到…」限制（各带启用
  开关、数字框与迷你滑块）。这就是手动双面打印的用法：先打奇数面，翻纸叠，再打偶数面。直接输入框也认
  `odd:1-99; even:2-100`。
- **逐页点选**：带页码的方格网格。单击切换一页，Shift+单击可从上一个点过的页整段填充，**全选** / **清空** /
  **反选** 作用于整个网格。没有拖选。

**输出**

- **三个页签**：**合并** / **奇数** / **偶数**，分别给出能直接粘进打印对话框「页面范围 / Pages」的字符串，
  例如 `1-5,8,10-13`。
- **复制按钮**：复制当前页签的内容，走 Clipboard API，失败自动回退 `execCommand`，复制成功有提示。
- **格式选项**：合并连续页（默认开）、分隔符（`,` / `, ` / `、` / `/` / 空格 / 换行）、倒序（手动双面的
  背面用）、按 K 页拆行（每行最多 K 页，方便一批一批放纸）。
- **实时更新**：边选边出结果，只读文本框也可以手动选中复制。

**记录与分享**

- **记录**：每次复制自动生成一条记录（时间、页数、输出预览），可以再次复制、恢复这次选择、删除单条或
  清空。
- **刷新不丢**：记录和当前选择都存在 `localStorage`。
- **分享链接**：一键复制带当前总页数与选择状态的链接（状态在 URL hash 里），打开即还原。纯离线，不含任何
  上报。

**设置与界面**

- **设置**：语言（自动检测，或 简体中文 / 繁體中文 / 日本語 / 한국어 / Français / Deutsch / English）、显示
  底部署名与相关项目（默认开）、标出没被选中的页、在顶部显示总览热力图、清除已保存的数据、恢复默认。设置存
  `localStorage`。
- **完全本机**：一个 `index.html`，双击就能用（`file://` 也行）；不加载任何外部字体、脚本或 CDN，不发任何
  请求。
- **白色主题 + 响应式**：桌面双栏（左控制、右输出），窄屏单栏。
- **键盘可用**：Tab 焦点环清晰，按钮带 `aria-label`，Esc 关闭弹窗。

## 用法

1. 用浏览器打开 `index.html`——双击文件，或直接用上面的三个入口之一。
2. 填上文档的总页数。
3. 挑页：总览图、逐页网格、范围控件、奇偶控件或直接输入都行。
4. 切到 **合并** 页签（一次只打一面时切到 **奇数** / **偶数**），点 **复制**。
5. 在浏览器打印对话框的「页面范围 / Pages」里粘贴，然后打印。

打印机一次只能放几张纸时，用 **按 K 页拆行**：输出会按每行最多 K 页拆好，一批一批放纸就行。

### 没有双面器时的手动双面

1. 填好总页数，复制 **奇数** 字符串，先打一面。
2. **按打印机的进纸说明翻面**——朝哪条边翻、哪一头先送纸，取决于机器，以及是长边翻还是短边翻。
3. 再复制 **偶数** 字符串打背面。如果背面顺序反了或方向倒了，在输出选项里打开 **倒序** 重新复制一次。
4. 先用两三页试印一次：比整摞重打便宜得多。

## 直接输入语法

这些写法直接敲进「或直接输入」框，不用点选：

| 写法 | 含义 |
| --- | --- |
| `1-5` | 第 1 到第 5 页 |
| `1-5, 8, 10-13` | 两段范围加单独的第 8 页；逗号分隔各项 |
| `odd` | 所有奇数页 |
| `even` | 所有偶数页 |
| `1-99/2` | 从第 1 页到第 99 页，步长 2（隔一页取一页） |
| `odd:1-99; even:2-100` | 奇数页 1–99 与偶数页 2–100，手动双面两面各用一条 |

各项之间可以用逗号、空格或「、」分隔；`odd:` 和 `even:` 可以并用，范围后面可以带 `/` 步长，例如 `1-99/2`。

## 隐私与离线

- **数据不出浏览器**：PagePicker 不发任何网络请求，不加载外部字体、脚本或 CDN 文件，没有统计、没有上报。
  它也不会去读你的文档——只认你填的页码。
- **只有一个文件**：`index.html` 自带全部东西，使用者无需构建、无依赖，`file://` 直接打开就能用。
- **数据存在哪**：当前选择、设置和记录都在本浏览器的 `localStorage` 里；分享链接把状态放在 URL hash 里。
  想清空就点 *设置 → 清除已保存的数据*，或者清掉浏览器的站点数据。
- **三个入口的存储不互通**：它们属于不同来源，所以挑一个固定用。
